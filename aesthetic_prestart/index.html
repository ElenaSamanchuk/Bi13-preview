Инструкция по скачиванию подложек для сторис:

— Откройте файл «Подложки для сторис», где доступны все подложки. (Файлы представлены в формате PNG и предназначены для скачивания).

— Нажмите на элемент (подложку).

— Скачайте, нажав на три точки в правом углу. (После скачивания подложки сохраняются в папке «Файлы» на вашем устройстве).

— Откройте скаченный элемент.

— Добавьте подложку в «Фото», нажав на символ в левом нижнем углу, и выберете «Сохранить изображение».

— Подложка будет добавлена в вашу галерею.

Теперь подложки будут доступны в вашей галерее, и их легко можно выбрать при редактировании сторис.

Совет: Чтобы подложки было легче находить, создайте для них отдельный альбом в галерее. Это позволит быстро находить их и использовать для оформления сторис, не пролистывая всю фотопленку.
